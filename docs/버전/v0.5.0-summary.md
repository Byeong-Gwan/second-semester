## 🐛 버그 수정

### 1. HTML 태그 표시 문제
**문제**: 뉴스 제목에 `<b>주요뉴스</b>` 같은 HTML 태그가 그대로 표시됨

**해결**:
- `app/api/news/route.ts`에 `cleanHtmlText()` 함수 추가
- HTML 태그 제거: `/<[^>]*>/g`
- HTML 엔티티 디코딩: `&lt;`, `&gt;`, `&amp;` 등

### 2. 환경 변수 로드 문제
**문제**: `.env.local.example`에 API 키를 넣어도 작동하지 않음

**해결**:
- `.env.local` 파일을 별도로 생성해야 함
- `cp .env.local.example .env.local` 명령어 사용
- 서버 재시작 필요

## 🔐 보안

### API 키 보호
- `.env.local`은 Git에 커밋되지 않음 (`.gitignore`에 추가됨)
- API 키는 서버 사이드에서만 사용
- Next.js API Route로 CORS 문제 해결

### CORS 처리
- 네이버 API는 브라우저에서 직접 호출 불가
- Next.js API Route를 프록시로 사용
- 서버에서 API 호출 후 결과 전달
