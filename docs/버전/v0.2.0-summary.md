## 💡 배운 점

### 1. Zustand Persist 문제
**문제**: 서버/클라이언트 hydration 불일치
**해결**: `mounted` 상태로 클라이언트 측 렌더링 보장

### 2. Checkbox 즉시 반응
**문제**: 내부 상태 사용으로 인한 지연
**해결**: Controlled Component 패턴 적용

### 3. 드롭다운 디자인
**문제**: 일관성 없는 디자인
**해결**: 공통 패턴 정립 및 적용

### 4. 날짜 선택 UX
**문제**: 여러 번 클릭 필요
**해결**: 드롭다운으로 빠른 선택

## 📝 참고 사항

### 코드 컨벤션
- 파일명: kebab-case
- 컴포넌트: PascalCase
- 함수/변수: camelCase

### Git 커밋 메시지
- `feat:` 새로운 기능
- `fix:` 버그 수정
- `refactor:` 리팩토링
- `docs:` 문서 수정
- `style:` 코드 스타일 변경

### 브랜치 전략
- `main`: 프로덕션
- `develop`: 개발
- `feature/*`: 기능 개발
- `fix/*`: 버그 수정
