### 2. 데이터 백업/복구 시스템 ✅

#### 새로 생성된 파일
1. **`lib/utils/backup.ts`** - 백업 유틸리티
2. **`app/mypage/settings/page.tsx`** - 설정 페이지

#### 구현 기능

##### 백업 (내보내기)
- JSON 파일로 모든 데이터 내보내기
- 파일명: `second-semester-backup-YYYY-MM-DD.json`
- 포함 데이터: 학습, 할 일, 출석

##### 복구 (가져오기)
- JSON 파일에서 데이터 복구
- 버전 체크 및 검증
- 자동 페이지 새로고침

##### 주요 함수
```typescript
exportData()        // 데이터 추출
downloadBackup()    // 파일 다운로드
importData()        // 데이터 복구
uploadBackup()      // 파일 업로드
```

### 3. 에러 처리 시스템 ✅

#### 새로 생성된 파일
1. **`components/ui/toast.tsx`** - Toast 알림 시스템
2. **`components/error-boundary.tsx`** - 에러 바운더리

#### 구현 기능

##### Toast 알림
- 4가지 variant: default, success, error, warning
- 자동 사라짐 (기본 3초)
- 우측 하단에 표시
- 슬라이드 애니메이션

##### ErrorBoundary
- React 컴포넌트 에러 캐치
- 사용자 친화적인 에러 화면
- 페이지 새로고침 버튼 제공
- 에러 메시지 표시

##### Provider 통합
```typescript
<ThemeProvider>
  <ErrorBoundary>
    <ToastProvider>
      {children}
    </ToastProvider>
  </ErrorBoundary>
</ThemeProvider>
```

## 🎯 해결된 문제

### 1. 데이터 손실 위험 🔴 → ✅
**Before**: localStorage만 사용, 캐시 삭제 시 모든 데이터 손실  
**After**: JSON 백업으로 데이터 안전성 확보

### 2. 에러 처리 부재 🔴 → ✅
**Before**: 에러 발생 시 빈 화면, 사용자 피드백 없음  
**After**: ErrorBoundary + Toast로 명확한 에러 처리

### 3. 사용자 피드백 부족 🟡 → ✅
**Before**: 인라인 상태 메시지만 사용  
**After**: 전역 Toast 시스템으로 일관된 알림
