# 학습 관리 기능 개선

## 📌 개요
학습 생성 시 기간 정보를 입력할 수 있도록 개선하고, 목록 및 상세 페이지에서 기간 정보를 확인할 수 있도록 구현

## 🎯 구현 목표
- 학습 생성 시 시작일/종료일 입력 가능
- 학습 목록에서 기간 정보 표시
- 학습 상세 페이지에서 기간 정보 확인

## 📝 변경 사항

### 1. 학습 스토어 업데이트
**파일**: `/lib/store/learnings.ts`

#### 인터페이스 변경
```typescript
export interface Learning {
  id: string;
  title: string;
  createdAt: string;
  startDate?: string;    // 추가
  endDate?: string;      // 추가
  progress: number;
  joined: boolean;
}
```

#### 함수 시그니처 변경
```typescript
// 이전
addLearning: (title: string) => string;

// 이후
addLearning: (title: string, startDate?: string, endDate?: string) => string;
```

#### 새로운 함수 추가
```typescript
updateDates: (id: string, startDate?: string, endDate?: string) => void;
```

### 2. 학습 생성 모달
**파일**: `/app/mypage/page.tsx`

#### 새로운 컴포넌트: LearningModal
```typescript
function LearningModal({ onClose }: { onClose: () => void }) {
  const { addLearning } = useLearningStore();
  const [formData, setFormData] = React.useState({
    title: "",
    startDate: "",
    endDate: "",
  });

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (!formData.title.trim()) return;
    addLearning(
      formData.title, 
      formData.startDate || undefined, 
      formData.endDate || undefined
    );
    onClose();
  };
  // ... 모달 UI
}
```

#### 입력 필드
- **제목**: 필수 입력
- **시작일**: 선택 입력 (date picker)
- **종료일**: 선택 입력 (시작일 이후만 선택 가능)

### 3. 학습 목록 카드
**파일**: `/app/mypage/page.tsx`

#### 기간 표시 로직
```typescript
{learning.startDate && learning.endDate ? (
  <span>
    {format(new Date(learning.startDate), "M/d")} ~ 
    {format(new Date(learning.endDate), "M/d")}
  </span>
) : learning.startDate ? (
  <span>{format(new Date(learning.startDate), "yyyy년 M월 d일")} ~</span>

```

#### 표시 형식
- **시작일 + 종료일**: `3/1 ~ 6/30`
- **시작일만**: `2026년 3월 1일 ~`
- **미설정**: `기간 미설정`

## 🎨 UI/UX 특징

### 모달 디자인
- 깔끔한 폼 레이아웃
- 날짜 입력 필드는 브라우저 기본 date picker 사용
- 종료일은 시작일 이후만 선택 가능 (`min` 속성 활용)

### 카드 디자인
- 기간 정보를 Calendar 아이콘과 함께 표시
- 간결한 날짜 형식 (M/d)
- 미설정 시 명확한 안내

### 상세 페이지
- 2열 그리드로 시작일/종료일 나란히 표시
- 요일 정보 포함 (예: 월요일)
- 미설정 시 "미설정" 텍스트 표시

## 💡 향후 개선 가능 사항
- 학습 기간 중 경과 일수 표시
- 남은 일수 계산
- D-day 표시
- 기간 대비 진척도 비교 그래프
- 기간 수정 기능 (상세 페이지에서)
