# v0.2.0 작업 개요

## 📅 작업 일자
2026년 2월 3일

## 🎯 주요 목표
학습 관리 시스템의 사용성 개선 및 새로운 기능 추가

## 📋 작업 요약

### 1. 학습 관리 기능 개선
- 학습 생성 시 기간(시작일/종료일) 입력 기능 추가
- 학습 목록 및 상세 페이지에 기간 정보 표시
- 학습 생성 모달 UI 개선

### 2. 할 일 관리 기능 개선
- 월간 달력 뷰에 년도/월 선택 드롭다운 추가
- 달력 날짜 hover 시 + 버튼으로 빠른 할 일 추가
- 체크박스 즉시 반응 문제 해결

### 3. 타임라인 페이지 재구성
- 주간 스케줄 뷰로 완전히 재설계
- 할 일 페이지와 데이터 통합
- 월/일자 선택 드롭다운 추가
- 세로 레이아웃으로 가독성 개선

### 4. UI/UX 개선
- Checkbox 컴포넌트를 Controlled Component로 변경
- 드롭다운 메뉴 디자인 통일
- 네비게이션 UI 개선

- React 18
- TypeScript
- Zustand (상태 관리)
- date-fns (날짜 처리)

- shadcn/ui
