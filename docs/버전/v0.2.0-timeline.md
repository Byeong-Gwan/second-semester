# 타임라인 기능 재구성

## 📌 개요
타임라인 페이지를 주간 스케줄 뷰로 완전히 재설계하여 할 일을 시간대별로 관리할 수 있도록 개선

## 🎯 구현 목표
- 주간 스케줄 뷰로 재구성
- 할 일 페이지와 데이터 통합
- 월/일자 선택 드롭다운 추가
- 세로 레이아웃으로 가독성 개선

## 📝 변경 사항

### 1. 페이지 용도 재정의

#### Before: 불명확한 타임라인
- placeholder만 있고 실제 기능 없음
- 용도가 모호함
- 할 일 페이지와 중복

#### After: 주간 스케줄 뷰
- **명확한 용도**: 주간 단위 할 일 시각화
- **할 일 페이지와 통합**: 동일한 `useTodoStore` 사용
- **빠른 추가**: 각 날짜에 + 버튼

### 2. 주간 스케줄 구조
**파일**: `/app/mypage/timeline/page.tsx`

#### 데이터 구조
```typescript
const weekStart = startOfWeek(currentWeek, { weekStartsOn: 1 }); // 월요일 시작
const weekDays = Array.from({ length: 7 }, (_, i) => addDays(weekStart, i));

const getTodosForDate = (date: Date) => {
  const dateStr = format(date, "yyyy-MM-dd");
  return todos.filter((t) => t.dueDate === dateStr);
};
```

#### 세로 레이아웃
```typescript
<div className="space-y-3">
  {weekDays.map((date) => {
    const dateTodos = getTodosForDate(date);
    const isToday = isSameDay(date, new Date());
    
    return (
      <Card className={isToday ? "ring-2 ring-primary" : ""}>
        <CardContent className="p-4">
          <div className="flex items-start gap-4">
            {/* 날짜 (왼쪽) */}
            <div className="flex flex-col items-center min-w-[80px]">
              <div className="text-xs text-muted-foreground">월</div>
              <div className="text-2xl font-bold">3</div>
              <div className="text-xs text-muted-foreground">2월</div>
              <div className="text-xs">2/5</div>
            </div>
            
            {/* 할 일 목록 (중앙) */}
            <div className="flex-1 space-y-2">
              {dateTodos.map((todo) => (
                <TodoItem todo={todo} />
              ))}
            </div>
            
            {/* + 버튼 (오른쪽) */}
            <button onClick={() => handleAddClick(date)}>
              <Plus size={20} />
            </button>
          </div>
        </CardContent>
      </Card>
    );
  })}
</div>
```

### 3. 월/일자 선택 기능

#### 헤더 레이아웃
```
주간 스케줄                    2월
이번 주 할 일을...        < 2일 ~ 8일 >
```

#### 월 선택 드롭다운
```typescript
<div className="relative">
  <button
    onClick={() => setShowMonthPicker(!showMonthPicker)}
    className="text-3xl font-bold hover:text-primary"
  >
    {format(weekStart, "M월", { locale: ko })}
  </button>
  {showMonthPicker && (
    <div className="absolute top-full mt-2 bg-background border-2 rounded-xl shadow-xl">
      {Array.from({ length: 12 }, (_, i) => i + 1).map((month) => (
        <button onClick={() => handleMonthSelect(month)}>
          {month}월
        </button>
      ))}
    </div>
  )}
</div>
```

#### 일자 선택 드롭다운
```typescript
<div className="relative">
  <button onClick={() => setShowDatePicker(!showDatePicker)}>
    {format(weekStart, "d일", { locale: ko })} ~ 
    {format(addDays(weekStart, 6), "d일", { locale: ko })}
  </button>
  {showDatePicker && (
    <div className="absolute top-full mt-2 bg-background border-2 rounded-xl shadow-xl">
      {weekDays.map((date) => {
        const dateTodos = getTodosForDate(date);
        const isToday = isSameDay(date, new Date());
        return (
          <button onClick={() => handleDateSelect(date)}>
            <div>{format(date, "M월 d일 (EEE)", { locale: ko })}</div>
            {dateTodos.length > 0 && (
              <div className="text-xs">할 일 {dateTodos.length}개</div>
            )}
            {isToday && <div className="text-xs font-bold">오늘</div>}
          </button>
        );
      })}
    </div>
  )}
</div>
```

## 🎨 UI/UX 특징

### 세로 레이아웃의 장점
- **가독성**: 할 일 내용을 충분히 표시
- **확장성**: 할 일이 많아도 스크롤로 대응
- **명확성**: 날짜별로 명확히 구분

### 날짜 정보 표시
```
월      요일
3   ←  날짜 (큰 숫자)
2월     월 정보
2/5     완료 통계
```

### 네비게이션
- **이전/다음 주**: `<` `>` 버튼
- **월 선택**: 월 클릭 → 1~12월 선택
- **일자 선택**: 일자 범위 클릭 → 주간 날짜 선택

## 📊 타임라인 vs 할 일 페이지 비교

| 구분 | 타임라인 | 할 일 페이지 |
|------|----------|--------------|
| **목적** | 주간 시각화 | 전체 관리 |
| **뷰** | 7일 세로 리스트 | 월간 달력 + 목록 |
| **용도** | 한눈에 확인 | 상세 관리 |
| **추가** | 날짜별 + 버튼 | 달력 hover + 버튼 |
| **필터** | 없음 (주간만) | 전체/진행중/완료 |
| **검색** | 없음 | 제목 검색 |
| **정렬** | 날짜순 고정 | 생성일/마감일/우선순위 |

## 💡 사용 시나리오

### 시나리오 1: 이번 주 확인
1. 타임라인 페이지 접속
2. 월~일 7일 할 일을 한눈에 확인
3. 오늘 날짜는 링으로 강조되어 쉽게 찾기

### 시나리오 2: 빠른 추가
1. 수요일에 할 일 추가하고 싶음
2. 수요일 카드의 + 버튼 클릭
3. 제목 입력 후 추가
4. 바로 수요일 카드에 표시됨

### 시나리오 3: 다른 주 확인
1. 월 클릭 → 원하는 월 선택
2. 또는 일자 범위 클릭 → 특정 날짜 선택
3. 해당 주의 할 일 확인
