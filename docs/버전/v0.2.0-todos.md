# 할 일 관리 기능 개선

## 📌 개요
할 일 페이지에 월간 달력 뷰를 추가하고, 날짜별 빠른 할 일 추가 기능 및 년도/월 선택 기능 구현

## 🎯 구현 목표
- 월간 달력 뷰 추가
- 날짜 hover 시 + 버튼으로 빠른 할 일 추가
- 년도/월 선택 드롭다운 추가
- 체크박스 즉시 반응 문제 해결

## 📝 변경 사항

### 1. 월간 달력 뷰
**파일**: `/app/mypage/todos/page.tsx`

#### 달력 구조
```typescript
const monthStart = startOfMonth(currentMonth);
const monthEnd = endOfMonth(currentMonth);
const daysInMonth = eachDayOfInterval({ start: monthStart, end: monthEnd });
const firstDayOfWeek = getDay(monthStart);

```

#### 7x5 그리드 레이아웃
- 일요일부터 토요일까지 7열
- 각 날짜 셀에 할 일 개수 표시 (완료/전체)
- 오늘 날짜는 primary 링으로 강조

### 2. 빠른 할 일 추가
**파일**: `/app/mypage/todos/page.tsx`

#### Hover 시 + 버튼 표시
```typescript
<div className="group relative min-h-[80px] rounded-md border p-2 hover:bg-accent/50">
```

5. 제목만 입력하면 할 일 추가 완료

### 3. 년도/월 선택 기능
**파일**: `/app/mypage/todos/page.tsx`

#### 상태 관리
```typescript
const [showYearPicker, setShowYearPicker] = React.useState(false);
const [showMonthPicker, setShowMonthPicker] = React.useState(false);
```

#### 년도 선택 드롭다운
```typescript
<div className="relative">
  <button
    onClick={() => setShowYearPicker(!showYearPicker)}
    className="text-lg font-bold hover:text-primary transition-colors"
  >
    {format(currentMonth, "yyyy년", { locale: ko })}
  </button>
  {showYearPicker && (
    <div className="absolute top-full mt-2 bg-background border-2 rounded-xl shadow-xl">
      {Array.from({ length: 10 }, (_, i) => new Date().getFullYear() - 5 + i).map((year) => (
        <button onClick={() => handleYearSelect(year)}>
          {year}년
        </button>
      ))}
    </div>
  )}
</div>
```

#### 특징
- **년도**: 현재 년도 기준 ±5년 범위 (총 10년)
- **월**: 1월~12월 전체 표시
- 현재 선택된 년도/월은 primary 색상으로 강조
- 드롭다운 외부 클릭 시 자동 닫힘
- 세로 리스트 형태로 깔끔한 디자인

### 4. 체크박스 즉시 반응 문제 해결

#### 문제 원인
Checkbox 컴포넌트가 내부 상태를 사용하여 `useEffect`가 실행되기 전까지 UI가 업데이트되지 않음

#### 해결 방법 1: Controlled Component로 변경
**파일**: `/components/ui/checkbox.tsx`

```typescript
// 이전: 내부 상태 사용
const [internal, setInternal] = React.useState(!!checked);
React.useEffect(() => setInternal(!!checked), [checked]);

// 이후: checked prop 직접 사용
const isChecked = !!checked;
onClick={() => onCheckedChange?.(!isChecked)}
```

#### 해결 방법 2: Hydration 처리
**파일**: `/app/mypage/todos/page.tsx`

```typescript
const [mounted, setMounted] = React.useState(false);

React.useEffect(() => {
  setMounted(true);
}, []);

const completionRate = mounted ? getCompletionRate() : 0;
```

## 🎨 UI/UX 특징
