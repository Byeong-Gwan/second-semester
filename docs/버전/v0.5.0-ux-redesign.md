# v0.5.0 UX 대대적 개선 (진행 중)

## 📅 작업 일자
2026년 2월 9일

## 🎯 작업 목표
**사용자 피드백**: "체크하고 할일 작성이 애매하고, 리스트가 이쁘지 않고, 진행도 수치화가 안 되어 있어서 쓰고 싶은 느낌이 안 든다"

### 핵심 문제점
1. ❌ 할 일 작성 UX가 애매함
2. ❌ 리스트 디자인이 매력 없음
3. ❌ 진행도 수치화 부족
4. ❌ 사용 동기 부족

---

## ✅ 개선 방향

### 1. 대시보드 페이지 신규 추가 🎯
**파일**: `app/dashboard/page.tsx` (신규)

**왜 만들었나?**
- 사용자가 앱을 열었을 때 "한눈에" 모든 것을 볼 수 있어야 함
- 진행도, 출석률, 할 일 등을 **시각적으로 명확하게** 표시
- 동기부여 요소 (연속 출석, 완료율) 강조

**주요 기능**:
- ✅ 핵심 지표 3개 카드 (출석률, 완료율, 연속 출석)
- ✅ 이번 주 출석 현황 (이모지로 시각화)
- ✅ 오늘의 할 일 (최대 5개 미리보기)
- ✅ 진행 중인 학습 (최대 3개 미리보기)
- ✅ 빠른 액션 버튼 (할 일 관리, 출석 체크)

**시각적 개선**:
- 🎨 카드에 hover 효과 (shadow-lg)
- 🎨 프로그레스 바로 진행도 명확히 표시
- 🎨 색상 코딩 (출석: 초록, 지각: 노랑, 결석: 빨강)
- 🎨 이모지 활용 (✅ ⏰ ❌ 🔥)
- 🎨 그라데이션 배경 (연속 출석 카드)

**수치화**:
- 📊 출석률 퍼센트 + 프로그레스 바
- 📊 완료율 퍼센트 + 프로그레스 바
- 📊 연속 출석 일수 + 불 이모지
- 📊 할 일 개수 배지
- 📊 학습 진행도 퍼센트

---

### 2. 플로팅 버튼 추가 ➕
**파일**: `components/ui/floating-button.tsx` (신규)

**왜 만들었나?**
- 할 일 추가가 "어디서 하는지" 명확하지 않았음
- 화면 어디서든 쉽게 접근 가능해야 함
- 모바일 앱처럼 직관적인 UX

**특징**:
- 우측 하단 고정 위치
- hover 시 확대 + 회전 애니메이션
- 그림자 효과로 눈에 띄게
- 터치하기 쉬운 크기 (56x56px)

---

### 3. 할 일 리스트 디자인 개선 (예정)

**현재 문제**:
- 단순한 border 스타일
- 우선순위가 눈에 안 띔
- 완료 상태가 명확하지 않음

**개선 계획**:
- 카드형 디자인 (그림자, 여백)
- 우선순위별 색상 강조 (빨강/파랑/회색)
- 체크박스 → 큰 원형 버튼
- 완료 시 축하 애니메이션
- 아이콘 추가 (우선순위, 마감일)

---

### 4. 진행도 시각화 강화 (예정)

**추가할 요소**:
- 주간 완료율 차트
- 일별 할 일 완료 개수 그래프
- 학습별 진행도 비교 차트
- 월별 출석률 추이

---

### 5. 동기부여 요소 (예정)

**연속 출석 스트릭**:
- 🔥 불 이모지로 시각화
- 7일, 14일, 30일 달성 시 배지
- 기록 갱신 시 축하 메시지

**성취 배지**:
- 🏆 첫 할 일 완료
- 🎯 10개 할 일 완료
- 📚 첫 학습 완료
- ⭐ 출석률 100% 달성

**축하 애니메이션**:
- 할 일 완료 시 confetti 효과
- 학습 완료 시 트로피 애니메이션
- 연속 출석 갱신 시 불꽃 효과
