## 기술적 세부사항

### 주간 뷰 로직
```typescript
// 현재 주의 월요일 계산
const weekStart = addDays(startOfWeek(today, { weekStartsOn: 1 }), weekOffset * 7);

// 7일 배열 생성
const weekDays = Array.from({ length: 7 }, (_, i) => addDays(weekStart, i));

// 해당 주의 일정 필터링
const weekItems = items.filter((item) => {
  const weekKeys = weekDays.map((d) => dateToKey(d));
  return weekKeys.includes(item.date);
});
```

### persist 미들웨어 동작
1. 상태 변경 시 자동으로 localStorage에 저장
2. 페이지 로드 시 localStorage에서 자동 복원
3. 저장 키: `timeline-storage`, `learnings-storage`
4. JSON 직렬화/역직렬화 자동 처리

### 타입 안전성
```typescript
// TimelineType enum으로 타입 제한
export type TimelineType = "study" | "language" | "solo" | "project" | "etc";

// Record로 모든 타입에 대한 색상 보장
const typeColors: Record<TimelineType, string> = { /* ... */ };
```
