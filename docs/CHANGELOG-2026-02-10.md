## 📊 출석률 계산 방식

### 기존
```
출석: 1점
지각: 0점
결석: 0점
```

### 변경 후
```
출석: 1.0점 (100%)
지각: 0.5점 (50%)
결석: 0점 (0%)
```

### 계산 예시
- 출석 2일, 지각 1일, 결석 1일: (2×1.0 + 1×0.5 + 1×0) / 4 = 63%
- 출석 3일, 지각 2일: (3×1.0 + 2×0.5) / 5 = 80%
- 지각만 2일: (2×0.5) / 2 = 50%
