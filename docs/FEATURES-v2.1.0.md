# Second Semester - 기능 문서 v2.1.0

## 📚 전체 기능 목록

### 1. 학습 관리 (Learning Management)
- 학습 과목/주제 추가 및 관리
- 학습 진행 상황 추적
- 학습 목록 조회

### 2. 학습 일지 (Study Log) 🆕 Enhanced
- **원형 타임라인**: 24시간 시각화
- **드래그 앤 드롭**: 시간 조정 (시작/종료/이동)
- **실시간 피드백**: 드래그 중 시간 표시
- **날짜별 관리**: 이전/다음/오늘 네비게이션
- **통계 요약**: 총 학습 시간, 세션 수, 과목별 시간
- **모바일 최적화**: 반응형 타임라인

### 3. 학습 회고 (Reflection) 🆕 NEW
- **날짜별 회고**: 매일 학습 돌아보기
- **자동 요약**: 학습 일지 데이터 자동 연동
- **카테고리 분류**: 5가지 카테고리
  - 📚 학습
  - 👤 개인
  - 💼 프로젝트
  - ❤️ 건강
  - 🏷️ 기타
- **기분 기록**: 4단계 기분 선택
- **마크다운 에디터**: 자유로운 형식 지원
- **회고 관리**: 저장/수정/조회
- **날짜 네비게이션**: 이전/다음/오늘

### 4. 타임라인 (Timeline)
- 주간 일정 관리
- 일정 추가/수정/삭제
- 날짜별 일정 조회

### 5. 할 일 (Todo)
- 할 일 목록 관리
- 완료 상태 토글
- 우선순위 설정

### 6. 출석 체크 (Attendance)
- 출석률 추적
- 출석 기록 관리
- 통계 확인

### 7. 대시보드 (Dashboard)
- 전체 통계 한눈에 보기
- 차트 및 그래프
- 빠른 링크

## 🎨 UI/UX 기능

### 반응형 디자인 🆕 Enhanced
- **모바일 우선**: 작은 화면 최적화
- **태블릿 지원**: 중간 크기 레이아웃
- **데스크톱**: 넓은 화면 활용
- **브레이크포인트**:
  - 모바일: < 640px
  - 태블릿: 640px - 1024px
  - 데스크톱: > 1024px

### 네비게이션 🆕 Enhanced
- **헤더 메뉴**: 아이콘 기반 빠른 접근
- **현재 페이지 표시**: 시각적 하이라이트
- **호버 효과**: 부드러운 트랜지션
- **모바일 최적화**: 아이콘만 표시

### 색상 시스템 🆕 Enhanced
- **카드별 고유 색상**: 시각적 구분
- **다크모드 지원**: 모든 색상 대응
- **호버 효과**: 테두리 + 배경색
- **일관된 테마**: 전체 앱 통일

### 테마
- **라이트 모드**: 밝은 배경
- **다크 모드**: 어두운 배경
- **자동 전환**: 시스템 설정 따라가기

## 🗄️ 데이터 관리

### Zustand Stores
1. **learningStore**: 학습 관리
2. **studyLogStore**: 학습 일지
3. **reflectionStore**: 학습 회고 🆕
4. **timelineStore**: 타임라인
5. **todoStore**: 할 일
6. **attendanceStore**: 출석

### LocalStorage 저장
- 모든 데이터 브라우저에 저장
- 자동 동기화
- 영구 보관

## 🔧 기술 스택

### Frontend
- **React 18**: UI 라이브러리
- **Next.js 14**: App Router
- **TypeScript**: 타입 안정성
- **Tailwind CSS**: 스타일링

### State Management
- **Zustand**: 상태 관리
- **Persist Middleware**: 데이터 영속성

### UI Components
- **Lucide React**: 아이콘
- **Shadcn/ui**: UI 컴포넌트
- **Custom Components**: 커스텀 컴포넌트

### Date & Time
- **date-fns**: 날짜 처리
- **ko locale**: 한국어 지원

## 🎯 사용 시나리오

### 일일 학습 루틴
1. **아침**: 오늘 할 일 작성 (Todo)
2. **학습 중**: 학습 일지 기록 (Study Log)
3. **저녁**: 학습 회고 작성 (Reflection)
4. **주간**: 타임라인으로 일정 관리

### 회고 작성 플로우
1. 날짜 선택
2. 학습 요약 자동 표시 확인
3. 카테고리 선택 (학습/개인/프로젝트/건강/기타)
4. 기분 선택 (최고/좋음/보통/안좋음)
5. 회고 내용 작성 (마크다운 지원)
6. 저장

### 학습 일지 작성 플로우
1. 날짜 선택
2. 새 기록 추가 (과목, 시작/종료 시간)
3. 원형 타임라인에서 시각적 확인
4. 드래그로 시간 조정 (필요시)
5. 통계 확인
